# Words of Wonders

Trainer profile for **Words of Wonders** on CrazyGames.

## Features

* **+999K Gems (`NUMPAD 1`)** — Injects 999,999 green gems into `SDK_DATA_21760` to buy unlimited hints and letter solves.
* **999 Hints & Hammers (`NUMPAD 2`)** — Sets free lightbulb hints and hammer reveals to 999 charges.
* **Timescale (`F11`)** — Cycle game simulation speed (1x / 2x / 5x) for fast animations.
* **Ad-Reward Bypass** — Skip rewarded ads directly for free lucky wheel spins with zero wait.
