# Idle Zombie Wave: Survivors

Trainer profiles and utilities for **Idle Zombie Wave: Survivors** on CrazyGames.

---

## Features

* **God Mode** — Complete barrier invulnerability.
* **One-Hit Kill** — Eliminate enemies in a single shot.
* **Wall Repair** — Instantly restore defensive structures.
* **Battle Scrap** — Add scrap currency directly during waves for in-match weapon and drone upgrades.
* **Speedhack** — Cycle match speed between 1.0x, 2.0x, and 5.0x.

---

## Quick Usage

* **Userscript:** Install `trainers/loader.user.js` in Tampermonkey. The profile loads automatically when visiting the game page.
* **Console:** Paste `v2.10/console-loader.js` into the browser console under the `idle-zombie-wave.html` frame context.

Press **`INSERT`** at any time to show or hide the overlay menu.
