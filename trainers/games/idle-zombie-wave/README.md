# Idle Zombie Wave: Survivors

Trainer profile for **Idle Zombie Wave: Survivors** on CrazyGames.

---

## Features

* **God Mode** — Complete barrier invulnerability.
* **One-Hit Kill** — Eliminate enemies in a single shot.
* **Wall Repair** — Instantly restore defensive structures.
* **Battle Scrap** — Add scrap currency directly during waves for weapon and drone upgrades.
* **Speedhack** — Cycle match speed between 1.0x, 2.0x, and 5.0x.

---

## Installation

Install the global loader script in Tampermonkey:
👉 **[Install `loader.user.js`](https://raw.githubusercontent.com/kentiers/web-trainers/main/trainers/loader.user.js)**

The trainer HUD will appear automatically when opening the game. Press **`INSERT`** to show or hide the menu.
