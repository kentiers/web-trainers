# Tile Clash

Trainer profile for **Tile Clash** on CrazyGames.

## Features

* **+999K Coins (`NUMPAD 1`)** — Injects 999,999 coins into `SDK_DATA_121168` -> `pistazo/save` for unlimited letter shuffle and tile hints.
* **Unlock 100 Levels & Max Streak (`NUMPAD 2`)** — Sets unlocked levels to 100 with 999 wins and 999 win streak.
* **Timescale (`F11`)** — Cycle game simulation speed (1x / 2x / 5x).
* **Ad-Reward Bypass** — Skip rewarded ads directly for free hints with zero wait.
