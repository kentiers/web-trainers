# Hangman

Trainer profile for **Hangman** on CrazyGames.

## Features

* **+999K Diamonds (`NUMPAD 1`)** — Injects 999,999 diamonds into `CrazyGames-Game-Hangman-v1.2` for unlimited letter reveals and hints.
* **Timescale (`F11`)** — Cycle game simulation speed (1x / 2x / 5x).
* **Ad-Reward Bypass** — Skip rewarded ads directly for free bonus clues with zero wait.
