# Chicken Hell

Trainer profile for **Chicken Hell** on CrazyGames.

## Features

* **+999K Gold Rings (`NUMPAD 1`)** — Injects 999,999 gold rings directly into `SDK_DATA_65663` to purchase all slingshot, rocket boost, gliding, and bounciness upgrades immediately.
* **Unlock All 7 Skins (`NUMPAD 2`)** — Unlocks every skin in the game (Alien, Pink, Yellow, Green, Turtle, Purple, and Default) by injecting their reverse-engineered GUID keys.
* **999 Free Wheel Spins (`NUMPAD 3`)** — Grants 999 free spins on the lucky wheel for cosmetic skins and permanent boosts.
* **Turbo Boost (`NUMPAD 4`)** — High-frequency synthetic event injector (~40 clicks/sec) to continuously fire rocket booster fuel in-flight for infinite flight distance.
* **Timescale (`F11`)** — Cycle game simulation speed (1x / 2x / 5x) for high-speed flight across hell.
* **Ad-Reward Bypass** — Skip rewarded ads directly for free daily gift boxes and egg boosts with zero wait.
