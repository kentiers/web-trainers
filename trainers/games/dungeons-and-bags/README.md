# Dungeons and Bags

Trainer profile for **Dungeons and Bags** on CrazyGames.

---

## Features

* **+500K Gold Coins** — Injects permanent gold coins directly into player profile.
* **+50K Diamonds** — Adds premium gems for card draws and store purchases.
* **Unlock All Heroes** — Unlocks all 5 playable characters instantly.
* **Max Permanent Upgrades** — Maxes out base Health, Strength, Luck, and Dodge attributes.
* **Timescale Speedhack** — Cycle gameplay speed between 1.0x, 2.0x, and 5.0x.
* **Instant Ad-Reward Bypass** — Background integration to claim free card packs and roulette spins without watching ads.

---

## Installation

Install the global loader script in Tampermonkey:
👉 **[Install `loader.user.js`](https://raw.githubusercontent.com/kentiers/web-trainers/main/trainers/loader.user.js)**

The trainer HUD will appear automatically when opening the game. Press **`INSERT`** to show or hide the menu.
