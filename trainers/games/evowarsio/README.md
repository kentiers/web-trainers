# EvoWars.io

Trainer profile for **EvoWars.io** on CrazyGames.

## Features

* **Tactical Zoom (FOV)** — Expand battlefield visibility (1.0x / 0.7x / 0.5x) to spot opponents and orbs earlier.
* **Practice Speedhack** — Adjust game tempo during offline practice mode (1x / 2x / 5x).
* **Ad-Reward Bypass** — Background integration to claim free chests without watching ads.

## Controls

* **`NUMPAD 1`** — Cycle Tactical Zoom (1.0x / 0.7x / 0.5x)
* **`F11`** — Cycle Speedhack (1x / 2x / 5x)
