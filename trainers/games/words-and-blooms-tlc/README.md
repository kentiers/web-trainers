# Words and Blooms

Trainer profile for **Words and Blooms** on CrazyGames.

## Features

* **Infinite Hints (`NUMPAD 1`)** - Hints never run out.
* **Infinite Shuffles (`NUMPAD 2`)** - Shuffles never run out.
* **Infinite Letters (`NUMPAD 3`)** - Letter bag pool never depletes.
* **Timescale (`F11`)** - Cycle speed (0.5x / 1.0x / 2.0x / 5.0x).
* **Zero-Reload Injection** - Applied directly in memory without restarting or reloading the puzzle board.
* **Ad-Reward Bypass** - Skip rewarded ads directly with zero wait.
