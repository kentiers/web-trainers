# Swarm Survivor

Trainer profile for **Swarm Survivor** on CrazyGames.

## Features

* **Overclocked Mothership (`NUMPAD 1`)** — Grants +10,000% HP (invulnerable ship), +5,000% Damage (one-hit disintegrate swarm), +2,000% Super Magnet (screen-wide gem/coin pull), and 85% Cooldown Reduction (continuous laser fire).
* **+999K Coins & +99K Gems (`NUMPAD 2`)** — Injects 999,999 gold coins and 99,999 gems for infinite shop purchasing.
* **Unlock All Weapons (`NUMPAD 3`)** — Unlocks all 12 heavy weapons and combat drones (Blaster Drone, Melee Drone, Cluster Bomb, Sniper, Boomer Missile, Drill Missile, Shotgun, Grenade, Sprayer, Orbiter, Missile Launcher, Blaster).
* **Timescale (`F11`)** — Cycle game simulation speed (1x / 2x / 5x) for 500% faster wave clearing.
* **Ad-Reward Bypass** — Skip rewarded ads directly for instant free revives and daily shop keys.
