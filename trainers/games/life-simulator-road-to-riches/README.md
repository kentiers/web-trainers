# Life Simulator: Road to Riches

Trainer profile for **Life Simulator: Road to Riches** on CrazyGames.

## Features

* **Speedhack** — Cycle game simulation speed (1x / 2x / 5x).
* **Ad-Reward Bypass** — Skip rewarded ads directly to claim instant cash, restore stats, and fast-forward time.

## Controls

* **`INSERT`** — Show / Hide Trainer
* **`F11`** — Speedhack Cycle (1x / 2x / 5x)
